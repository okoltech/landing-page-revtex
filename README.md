# Política de Privacidade — Revtex

Página estática pronta para publicar no GitHub Pages e usar no Google Play Console.

## Arquivos

- `index.html` — a página
- `style.css` — os estilos

## Antes de publicar

1. Substitua `seu-email@exemplo.com` (em `index.html`) pelo seu e-mail de suporte real.
2. Confira a data "Última atualização" no topo e no rodapé.

## Publicar no GitHub Pages

```bash
git init
git add .
git commit -m "Política de Privacidade Revtex"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPO.git
git push -u origin main
```

No repositório: **Settings > Pages > Branch: main / root > Save**.
A URL gerada (ex.: `https://SEU-USUARIO.github.io/SEU-REPO/`) é a que você cola no
**Google Play Console > Conteúdo do app > Política de privacidade**.
